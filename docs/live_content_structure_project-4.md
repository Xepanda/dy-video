## 5. 主播话术精选（ASR 审核后台词）

按成片场景顺序摘录对应时段的主播原声台词（Faster-Whisper 转录 + 语境纠错 + 执行者审核）：

**场景 1（穿搭推荐）**：你可以看下这种上来效果；你上衣宝宝；你上衣如果你家里；潜色衣服比较多的话；你给我拍链麦色；赶紧没看见没

**场景 2（面料讲解）**：纱线手里非常非常细腻；细腻的纱线就会有这种羊毛非常细腻；它就会像羊绒一样非常的舒适

**场景 3（版型展示）**：这叫护子整个的版型；这么厚实的面料；还能给大家做到说哎如此的显瘦；是因为我们的手所有的侧风是往前移的

**场景 4（穿搭推荐）**：现货没有了；跑达那一波了；也是快的那一波的；它没有慢的；两个颜色帮我准备一下

**场景 5（穿搭推荐）**：燕麦色；给大家摄一下燕麦色；可以啊；尺码三个S码一百斤；一百一数一百三；卡码这一件是什么颜色

**场景 6（穿搭推荐）**：我们全部现货在仓；现在你拍都是鲜窝在仓的；这都是黑色的；然后这个颜色是燕麦色；黑色搭燕麦色去搭多好看

**场景 7（穿搭推荐）**：黄色表白的那个；他买了两个；天哪；然后这个颜色就是；这个颜色我觉得；它有点偏这种大香灰的颜色其实

**场景 8（穿搭推荐）**：来1号灵界鸡；来S码100；今天码100；手机直达转达130；无异起球；在我没发货之前
