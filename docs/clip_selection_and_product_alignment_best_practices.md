# 直播电商短视频剪辑与素材选段最佳实践指南

> 基于多次多源混播直播剪辑实战沉淀的工程经验总结（2026-11 更新）  
> 核心原则：**商品主体强绑定、气口边缘防口误、特效人脸双安全、漏斗占比硬契约**

---

## 1. 痛点场景与根因分析

在多源素材剪辑与电商带货短视频合成中，常出现以下四类关键失误：

| 异常现象 | 业务表现 | 技术根因 | 防御机制 |
| :--- | :--- | :--- | :--- |
| **主体品类错配** | 上衣带货视频中混入大量裤装、皮裤、外套或鞋包讲解 | 选段器基于全池关键词覆盖率判定，漏斗 Styling 打分对穿搭词（裤子/西裤）误加分，未在分镜级做品类负向排除 | `verify_clip_product_alignment.py` 分镜级负向品类拦截 |
| **素材清单污染** | 显式指定 `raw_video_paths` 后仍摄入了同目录下的历史混播无关文件 | `_collect_source_videos` 在获取到显式列表后仍向下穿透扫描父目录 | 显式列表强隔离：`if paths: return paths`，绝不回退穿透 |
| **价格零残留被误杀** | 主播面料口误结巴（如「3030多点羊毛」）被 ASR 质检识别为四位数字疑似价格表达 | 选段切点盲目切在结巴句首，未做语音气口精细调整与口误数字过滤 | 起点微调吸附至顺畅语流气口（如 89.40s 直接从「纱线手里非常细腻」切入） |
| **片尾极限词触发拦截** | 主播码数讲解尾句提到「最大穿到130斤」，触发平台违规词 | 切片未在句末极限词前做安全截断 | 精准截断：保留「S码100斤，M码115斤」，提前在极限词前截断 |
| **特效叠加层压脸** | 翻转（hflip）或推镜（zoom）分镜中，挂角贴纸遮挡主播面部 | 贴纸避让算法仅基于原始未变换帧计算人脸坐标，未映射至成片画布坐标系 | 坐标镜像映射 + 推镜放缩变换（考虑动态居中与 y_anchor） |

## 2. 工程规范与执行准则

### 2.1 S0 阶段：素材准入与强隔离契约
- 当任务配置 `job_spec.json` 中显式提供了 `raw_video_paths` 列表时，总导演与调度器**必须仅采用该列表中的文件**。
- 禁止穿透扫描父目录，防止同目录下同一天的其他品类录播或历史成片被误摄入。

### 2.2 S1/S1.5 阶段：同音错词归一与品类预检
- 针对针织/羊毛高频专场口播词，统一在 `STATIC_DOMAIN_HOMOPHONES` 补充同音映射（如 `浑纺->混纺`, `颜麦色->燕麦色`, `杀线->纱线`, `气球->起球`, `板型->版型`, `先货->现货`, `在仓` 等）。
- 绝不改写非本品语句伪造本品话术：对于非本品话术，正确的策略是**物理选段排除**，而非字幕强改。

### 2.3 S2 阶段：分镜级商品对齐门禁（`verify_clip_alignment`）
编排出的每一个分镜，必须通过以下四项硬性核验：
1. **负向词排查**：上装排除下装专有词（裤/库长/皮裤/石墨烯），下装排除上装专有词。
2. **数字/价格残留排查**：排查连续3~4位纯数字、非单位修饰的口误数字（排查 `3030多点`，放行 `100斤`, `S码`, `30%`）。
3. **极限词拦截**：截断边缘处的「最大」、「顶级」、「最好」等平台违禁词。
4. **漏斗占比契约**：
   - 面料（Fabric）≤ 25.0%（防参数堆砌，留存率核心）
   - 黄金前奏（Hook）≥ 10.0%
   - 版型身材（Fit）≥ 15.0%
   - 场景穿搭（Styling）≥ 25.0%
   - 促单收口（Closing）≥ 10.0%

### 2.4 S4 阶段：特效分镜的人脸安全数学模型
挂角贴纸在成片中的坐标必须考虑当前分镜施加的视频滤镜：
- **水平镜像（`hflip`）**：
  $$\text{face\_x0}_{\text{canvas}} = \text{OUT\_W} - \text{face\_x1}_{\text{src}}$$
  $$\text{face\_x1}_{\text{canvas}} = \text{OUT\_W} - \text{face\_x0}_{\text{src}}$$
- **缓入推镜（`zoom > 1`）**：
  $$\text{center\_x} = \text{OUT\_W} \cdot (1 - 1/z) / 2$$
  $$\text{center\_y} = \text{OUT\_H} \cdot y\_anchor \cdot (1 - 1/z)$$
  $$\text{face\_canvas} = (\text{face\_src} - \text{center}) \cdot z$$
- 贴纸避让判定优先在默认顶部边角（$y=300$）左右择优；若安全间距 $<30\text{px}$，采用步进下移机制（$y=520, 740, 960$），取满足安全间距且最靠近挂角高度的位置，严禁粗暴推向屏幕正中破坏版式。
