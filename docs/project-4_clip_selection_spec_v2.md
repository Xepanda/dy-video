### 0.2 三条 MUST 记住的口径

1. **"成片里都是裤子"指 v1，不是当前主路径文件**；若播放器仍显示裤装，属缓存或打开的是 `_v1_rejected` 备份。
2. **当前版的"干净"来自人工按 10s 窗口裁出 4 段纯主商品素材（`hero_only/`，共 322s），不是选段器自己判对的**。同一套选段逻辑喂原始 6 段仍会选出裤子 → 机制性缺口未修。
3. **"关键素材没选到"在当前版里依然成立且更突出**（见 §1.2）。此外 32 帧复核发现约 37–63s 主播**身穿黑色上衣、手持米灰针织上衣**讲解，属"本品出镜但主体弱一致"；上一版 10 帧抽样把它判成 10/10 本品，抽样密度不足会掩盖问题。

## 一、问题归因

### 1.1 G-01｜精准率缺口：商品主体从未进入选段目标函数

S2 优化的是「类目配额填满 + 句子边界 + 总时长」，没有"这一段是不是在讲本品"这一维。

| 层 | 具体失效 |
| :--- | :--- |
| 防错配规则 | `has_top_kw` 白名单含「搭 / 上身 / 衣服 / 大衣 / 外套」等极宽泛词，ASR 句合并后的 block 几乎必命中 → `is_pure_pants=False`；`fit`/`styling` 类目纯他品块只扣 15 分（`hook`/`fabric` 才扣 50）；`STYLING_KEYWORDS` 把「裤子 / 裤腿 / 西裤 / 卫裤」列为**正分关键词** |
| 实测后果 | v1 `selection_meta.funnel.styling = 27.56s`，占成片 **44%** 且为最大配额；选段器不是"漏掉"主商品，而是**主动把裤装话术当搭配素材选进来** |
| 判定粒度 | S1.5 的 C1/C2 把 **6 源 1185s / 729 句 ASR 全文**拼成一个字符串算覆盖率（v1 实测 C1=1.0、C2=1.0、0 WARN）；C3 只比**封面帧**与商品图；无任何断言检查「S2 选出的这 10 个分镜」 |
| 门禁 | `consistency_check.enforce_level: WARN`；QC 38 项全为时长/帧率/响度/黑帧/字幕几何/贴纸人脸/ASR 相似度等物理与版式指标 |

**结论**：`ALL PASS` 与「主角搞反」可以同时成立。这是结构性缺口，不是单点参数错误。

### 1.2 G-02｜召回率缺口：关键片段漏选（当前版仍存在）

把主商品素材池（4 源）与成片烧录字幕按 7 类必备卖点做词频对照：

| 卖点类目 | 素材池命中 | 成片字幕命中 | 判定 |
| :--- | ---: | ---: | :--- |
| 成分 / 面料（绵羊毛、混纺、针织） | 12 | 2 | 严重不足 |
| 颜色 / 色卡（燕麦色、大香灰、灰调） | 37 | 3 | 严重不足 |
| 工艺 / 细节（纱线、一线成型、领形） | 8 | 5 | 偏集中 |
| 版型 / 上身（版型、显瘦、宽松） | 5 | 2 | 偏弱 |
| 品质佐证（细腻、顺滑、不起球） | 11 | **9** | **过度重复** |
| 规格 / 尺码（S/M/L、体重区间、尺码表） | 3 | **0** | **漏选** |
| 交易 / CTA（现货、加单、1 号链接） | 19 | **1** | **漏选** |

- `hero_02_141614`（**完全未用**）恰好承载最关键的转化信息：「31 个绵羊毛浑仿」「两个颜色…燕麦色偏灰调」「全部现货在仓」「S 码穿到 100 斤 / 115 斤 / 最大穿到 130」「1 号链接、先拍现货」。
- `hero_05_231446`（**完全未用**）承载「显瘦 / 版型 / 通勤 / 一线成型 / 现货 / S 码」。
- 成片 **7/10 分镜来自 `hero_03`** 一段连续的「纱线细腻 → 一线成衣 → 精简」话术（约 45s / 64s），信息高度重复；`hero_02`、`hero_05` 使用率 0。
- 根因：**仓库从未定义"关键片段"是什么**。没有必备卖点清单，选段器只能收敛到"最容易命中关键词、句子最完整"的那一小段；成片在"质感"上讲了 9 次，在"是什么 / 什么色 / 什么成分 / 多大码 / 怎么买"上几乎空白。

### 1.3 G-03｜信号失真：唯一依据（ASR 文本）恰好在卖点词上错得最多

| 原始转录 | 正确 | 对选段的影响 |
| :--- | :--- | :--- |
| 浑仿 / 浑坊 / 浑纺 | 混纺 | 「混纺」关键词命中失败 → 成分段打分低 |
| 刹线 / 杀线 / 沙线 | 纱线 | 工艺段打分不稳 |
| 颜麦色 | 燕麦色 | 颜色段打分低 |
| Smart 穿到 100 斤 | S 码穿到 100 斤 | 尺码信息丢失 |
| 全民扣衣 / 扣小衣 | 扣 1 | CTA 被当作无意义互动 |
| 1 号练接 / 灵界鸡 | 1 号链接 | CTA 段漏选 |
| 牌现货 / 先货 / 在藏 | 拍现货 / 现货 / 在仓 | 库存话术漏选 |
| 气球 / 板型 | 起球 / 版型 | 品质与版型卖点漏选 |

已补 11 条词表规则，但「浑仿 / 刹线 / 灵界鸡」等变体仍残留。**关键词匹配对 ASR 错字零容错，是"关键片段漏选"的直接技术原因**；且 §12.3 的 Agent 语义复核原本是事后审计，未前置到打分之前。

### 1.4 G-04｜通道缺失：画面信息完全没进选段

- 尺码表、颜色卡、吊牌、商品全貌、面料特写都是**画面信息**，ASR 里没有；纯文本选段不可能主动召回"举尺码表"这类关键镜头（当前成片能看到尺码表卡属碰巧选中，不是判定结果）。
- 现有识图只产出**人和构图**特征：人脸/姿态/清晰度（封面候选）、`body_h / span / shoulder_w / face_area / fabric_block / wrist_motion / torso_motion / framing`（`extract_shot_features`）、镜头边界。零"商品"特征。
- `requirements.yaml` §60 已有「允许丢段，只保留商品介绍/卖点/演示」，§C7 已有「模特衣着与商品图片一致（CLIP 阈值 0.75）」——**需求写在纸上，但没有对应断言**。

### 1.5 G-05｜约束失效：错配不会阻断下游

WARN 不拦截；没有准入白名单；阶段间不传递商品标签；S4 组装不复核；S5 不复算。一旦 S2 选错，后续阶段会忠实地把错误渲染成成片。且 `build_plan.py`、`check_spec_material_consistency.py`、QC **各自内置一套词表**，没有唯一真值源，改一处另两处不跟随。

### 1.6 G-06｜验收方法失效

上一轮用 10 个时间点抽帧即宣称「10/10 本品」，并把「默认全部视为未发现问题」的人工复核表原样交付；而该表第 2/5/13 项恰恰就是商品主体验收项。**QC 全绿只证明物理指标达标，不证明内容正确**；抽样密度不足 + 空表交付，是本次问题被发现得晚的直接原因。

## 四、判定与过滤规则

### 4.1 关键片段判定标准（K 系列）

**K-01（MUST）** 关键片段 = **主体合格 ∧ 片段有效**，两者缺一不可。

**K-02｜主体合格（三通道）**

| 通道 | 合格条件 |
| :--- | :--- |
| 文本 | 句级标签 = `本品`；不命中任何他品词/他品语义模式；关键卖点词按 `asr_homophones` 归一后命中 |
| 视觉 | 与商品锚点图相似度 ≥ 标定阈值（CLIP 建议 0.75 起、须用 golden set 标定）；或降级口径下主色/明度/廓形与锚点一致；**本品为视觉主体**（非背景、非仅手持他品） |
| OCR | 无他品字样；出现「尺码表 / S M L / 体重区间」记为本品**强正信号** |

**K-03（MUST）** 任一通道判 `他品` → 硬排除；三通道均不反对且至少一通道强支持 → 主体合格。

**K-04｜片段有效**

- 命中 **≥1 类尚未被已选片段覆盖**的必备卖点（信息增量优先）；
- 起止落在 ASR 句末 **±0.45s**（沿用 R1），句子语义完整，不跨换款点；
- 单段 **3–12s**；非黑帧、非纯人脸空镜、非静止重复帧；
- 与前后片段在景别或角度上有变化。

**K-05｜卖点优先级**

| 级别 | 类目 | 说明 |
| :--- | :--- | :--- |
| **P0 必选** | 成分/面料、颜色/色卡、规格/尺码、交易 CTA | 决定「卖什么 / 什么色 / 能不能穿 / 怎么买」，转化关键，当前成片最缺 |
| **P1 应选** | 工艺/细节、版型/上身、品质佐证 | 建立信任，至少各 1 段且避免过度重复 |
| **P2 可选** | 氛围、互动、口头禅 | 仅时长富余时补 |

**K-06（MUST）** Hook 特别规则：前 3s 必须让观众明确「卖的是这件针织上衣」（本品名出现或本品全貌画面）。禁止用「退货率虚高 / 内里 / 随便去刷」等无主体句开场。当前成片开头「纱线用的超级超级的细腻」有质感无主体，**不合格**。

**K-07（SHOULD）** 「本品出镜但主体弱一致」形态（主播身穿他色上衣、手持本品讲解）单独打标计数，不得与"穿着本品"混为一谈；占比超阈值记 WARN。

**K-08（MUST）** 每个入选/排除的 block 都要记录判定依据（三通道分数、命中卖点、来源时间戳、排除原因），落盘供审计。

### 4.2 无关内容过滤规则（F 系列，全部 BLOCK，直接丢弃，不扣分保留）

**F-01｜词表硬排除**：命中 `negative_terms` 任一项即排除。完整词表见 §2.4，含：裤 / 库长 / 毛泥裤 / 膝盖 / 裤腿 / 西裤 / 卫裤 / 皮裤 / 内里 / 棉浮 / 舔充物 / 退货率 / 加 100 条 / 「83848586」等裤长数字串。**同音字、繁体、ASR 常见错写 MUST 全部纳入**。

**F-02｜句级语义排除**：即使不含显式品类词，只要判定「讲的是另一件商品」即排除。典型：「内里」「填充物」「穿起来腿膝盖弯的时候」「退货率虚高」。

**F-03｜视觉排除**：画面主色近黑且廓形为两条纵向裤管；或视觉相似度低于阈值；或 OCR 出现「裤长 / 毛呢 / 填充」字样。

**F-04｜时间邻域扩展（MUST）**：命中他品的 block **前后各扩展 5s 一并剔除**，防止换款过渡句、上一段尾句、下一段首句混入；连续命中则整段换款区间整体剔除。

**F-05｜泛词陷阱修正（MUST）**：从 `has_top_kw` 本品白名单删除「搭 / 上身 / 衣服 / 大衣 / 外套」；`allowed_category=上装` 时把裤装词从 `STYLING_KEYWORDS` 正分中移除；纯他品块直接 `_drop`，不再只扣 15 分。

**F-06｜语义改写禁令（MUST）**：ASR 纠错只处理同音错字/字形/空格归一。把「毛呢裤」写成「针织上衣」属制造虚假宣传，明令禁止；正确处置是剔除该 block 并重选。`asr_homophones` 中「毛泥裤→毛呢裤」「库长→裤长」「棉浮→棉服」仅纠错、不改变品类，纠错后仍按 F-01 排除。

### 4.3 避免同类错误进入后续剪辑的约束（C 系列）

| # | 约束 | 落地位置 | 级别 |
| :--- | :--- | :--- | :--- |
| C-01 | **唯一真值源**：所有阶段只读同一份商品锚点契约，禁止各阶段内置词表 | 全阶段 | MUST |
| C-02 | **白名单强锁**：非白名单 block 不得进入 `plan`；`plan` 缺 `clip_schema` 任一字段即判非法并中止 | S1.5 → S2 | MUST |
| C-03 | **闸门升级**：`consistency_check.enforce_level` 由 WARN 升 BLOCK；新增 C5/C6 均 BLOCK | S1.5 / S5 | MUST |
| C-04 | **阶段间契约**：S2→S4 传递白名单 ID；S4 组装前逐 clip 比对；S5 复算；不一致即中止，**不写最终成片文件** | S2 → S4 → S5 | MUST |
| C-05 | **成片级复检**：对最终 MP4 做每 2s 网格抽帧 + 烧录字幕/原声他品词表 + 卖点覆盖表复算，作为交付前置条件 | S6 | MUST |
| C-06 | **缓存失效纳入指纹**：锚点契约、词表、素材集任一变更 MUST 进入阶段缓存 key（本次已两次因缓存污染返工） | S0 | MUST |
| C-07 | **可追溯**：每个 clip 记录命中卖点、三通道分数、来源时间戳；每个被排除 block 记录排除原因 | S2 / S6 | MUST |
| C-08 | **复核不可外包**：人工/Agent 复核表 MUST 逐项填写结论才允许签署，禁止「默认全部视为未发现问题」；其中「前 3s 主体明确」「非主题款已删除」「话术与画面匹配」为强制项 | S6 | MUST |
| C-09 | **回归保护**：每次规则改动 MUST 在 golden set 上重跑 §5.1 指标，指标不回退才允许合入 | 持续 | MUST |

### 4.4 边界禁令（B 系列）

### 5.2 golden set 定义与标注规范（MUST）

把本次 6 段原始素材按 **10s 窗口**人工标注为 `本品 / 他品 / 中性`，并额外标出**必备卖点时间窗**（例：`hero_02` 的「31% 绵羊毛混纺」段、燕麦色段、尺码段、现货 CTA 段）。用途：

1. 标定 CLIP / 直方图 / OCR 阈值，不靠拍脑袋定 0.75；
2. 每次规则改动后重跑 M01–M08，确认不回退；
3. 计算 **关键片段召回率** = 被选中的 golden 卖点窗 / golden 卖点窗总数，目标 **≥0.8**（BLOCK 级补充指标 M15）。
4. 标注须双人独立、分歧复核，标注文件纳入版本管理。

### 5.3 验收判定式（交付的充要条件）

一次交付 MUST 同时满足：

```
QC.all_passed == true
AND COUNT(BLOCK FAIL) == 0
AND M01 == 0 AND M02 == 1.0 AND M03 >= 6/7
AND M05(源数) >= 3 AND M05(单源占比) <= 0.40
AND M06 == 0 AND M07 >= 0.95 AND M08 == 0
AND M10 == 1.0 AND M11 == 1.0 AND M15 >= 0.8
AND 复核表全部条目已填写结论（C-08）
AND 成片每 2s 网格抽帧已目视复核（C-05）
```

任一不满足 → 退回 S2 重选，**不得签署交付**。

### 5.4 回归流程

`改规则 → 重跑 golden set → 复算 M01–M15 → 与基线比对 → 无回退才合入 → 更新基线表`。每次回归结果写入 `output/<project>/selection_regression.json`，与 QC 报告、生成清单一同归档。
