## 0. 一页结论

**定性**：这份文档是**人工剪辑师的作业规范**（以"应该怎样剪"的经验判断为主），本仓库是**自动化流水线 + 量化门禁**（以"能不能自动判定"为主）。两者不是替代关系，而是"目标态"与"当前实现"的差距清单。

**3 处硬冲突**（照文档做就必须改架构，不是加参数能解决）

| # | 文档要求 | 仓库现状 | 冲突性质 |
| :--- | :--- | :--- | :--- |
| 1 | **全片不要字幕、不要任何文字**（花字/贴纸/价格标签一律不要） | 默认烧 ASS 字幕 + 顶部品牌条 + Hook 卡 + 片尾 CTA + 挂角贴纸；QC 有 6 类字幕断言 | 产品形态冲突：需要"纯画面 profile"，且字幕类断言必须能优雅跳过 |
| 2 | 成片 **40–70s**，优先 45–60s | `video.duration_range: [45, 65]`，spec 只允许在该区间内收窄 | 40–44s 的成片当前做不出来 |
| 3 | 语速提到原素材 **1.1–1.2 倍** | 无任何变速能力（全链 `setpts=PTS-STARTPTS`，无 `atempo`） | 新增能力，且会连锁影响字幕/消音/转场/时长折算 |

**2 个真空白**（仓库完全没有，且价值高）

1. **多色处理**：颜色清单、偏好色时长占比（2 色 60–70% / 3 色 45–55%…）、"说某色→紧接画面必须是对应色"的硬规则——全无。这是女装切片的高频场景。
2. **主题款明确（0–5s）**：文档把它列为双任务之一（强钩子 + 让观众确认"这次讲的是哪一件"），仓库只有 Hook 卡**文字**承担该职能——而文档禁止文字，所以等于没有机制。

**5 处可直接吸收**（低成本、不破坏现有架构）

| 点 | 为什么值得 | 成本 |
| :--- | :--- | :--- |
| 参数类内容占比 ≤ ~20%（4~5 分之一） | 我们有 `funnel.fabric: 8–20s`，折算下来占比 13–43%，**上限太松** | 改 1 个阈值 + 1 条 QC 断言 |
| 句子级赘述去重（"黑色一套，黑色一套…"） | 现只有字符级叠词去重（"真的真的"），跨段重复句没处理 | 相邻段文本相似度判定，~40 行 |
| Hook 卖点优先级表（显白>显瘦>小个子适配>反差>痛点>场景>福利） | 现 `HOOK_KEYWORDS` 是平铺词表，无优先级 | 词表加权重 |
| 头顶距顶 ≤ 画面高 17%（等比放大、底边不动、左右对称裁切） | 现仅有封面构图有此约束（`head_top_min_ratio: 0.13`），**视频分镜端没有** | 复用 `normalize_subject_framing` 思路，作用于每个 clip |
| 成片落到素材目录 | 现固定输出 `output/<pid>/`，人工还得手动拷 | 一个复制步骤（建议做成可选） |

**已被覆盖，无需动作**：违禁词清单（文档给的飞书文档就是我们已经镜像成 `contracts/violation_words.yaml` 的那份）、价格数字禁止、交易叫卖删除（库存/上车/几号链接/发货，已有黑名单）、转场不切半句（句子边界对齐 + xfade/acrossfade）、音量统一不爆音（−14 LUFS + limiter）、不模拟主播声音（本流水线只做真实素材选取，从不 TTS）。

**不建议采纳**：助播分轨删除（素材里基本只有主播，且需 diarization 重投入）、"不额外移动画面强行居中"（那是封面构图语境的规则，视频端不适用）、"稀缺"重定义（本质是话术引导，仓库侧已禁止虚假稀缺，无需新增机制）。

| 分类 | 项数 | 清单编号 | 说明 |

| **① 已有断言可覆盖** | 8 | 3（卖点完整）、6（删交易叫卖）、7（无价格数字）、8（违禁词）、10（音量）、17（时长）、23（句子完整/转场自然）、26（少参数——部分，需收紧阈值） | 直接映射到现有 QC：`subtitle_assert_zero`、`violation_words`、`loudness_lufs`、`duration_range`、`A11`、句子边界 |
| **② 可低成本新增断言** | 7 | 1（钩子非参数）、2（主题款明确，ASR 侧）、12/30（参数占比 ≤20%）、13（贵材质 ≥1 处）、14（头顶 ≤17%）、18（颜色清单建立）、22（颜色转场一致） | 多为"统计现有产物 + 阈值判定"，1–2 天/项 |
| **③ 需新增能力** | 6 | 19（偏好色占比）、20（颜色人群表达）、21（多色遮挡优先）、24（赘述去重）、27（痛点前置）、32（五步框架） | 需颜色标注/相似度/语义判断，中高成本 |
| **④ 只能人工或采样审核** | 13 | 4/5（换画面重复）、9（助播）、11（助播缺失补齐）、15（清晰度主观）、16（无文字——可自动化但依赖 §0-1 改造）、25（搭配完整）、28（话术-画面匹配）、29（情绪瞬间）、31（促单轮次）、33（不硬编）、34（主题款聚焦） | 建议放进"抽帧审核台"（SOP §9 已列为工具缺口） |

> 结论：34 项里 **15 项（44%）可完全自动化**，6 项需新增能力，13 项只能人工/采样——这说明文档本身更像"人工质检清单"，把它整体塞进流水线既不现实也无必要。

## 3. 建议采纳清单（按优先级）

### P0 — 低成本、直接改善现有成片（建议本迭代就做）

| # | 改动 | 落点 | 验收 |
| :--- | :--- | :--- | :--- |
| P0-1 | **参数占比上限收紧**：`funnel.fabric.max` 20 → 12，并加 QC「fabric 时长占比 ≤ 0.25」 | `constraints.yaml` + `qc_auditor` | 新断言在 3 条历史成片上跑通 |
| P0-2 | **句子级赘述去重**：相邻段 `text` 相似度 ≥0.8（difflib）时保留情绪更强/更完整的一条 | `build_plan`（块内去重） | 单测覆盖"黑色一套×2"用例 |
| P0-3 | **Hook 卖点优先级**：词表加权重（显白/显瘦/小个子/反差 > 通用赞美） | `build_plan._segment_score` | 同一素材 hook 选段不变差 |
| P0-4 | **主题款明确断言**：前 5s ASR 需出现「这件/这条/这双/这个 + 核心词」或核心词本身 | `qc_auditor`（WARN 起步） | 现有 3 条成片不误报 |

### P1 — 需要新增能力（下一迭代，建议先做 1 项验证）

| # | 改动 | 关键风险 | 建议做法 |
| :--- | :--- | :--- | :--- |
| P1-1 | **纯画面 profile**（无字幕/贴纸/Hook/CTA/品牌条） | 6 类字幕断言失效、违规词策略退化（只剩音频） | 给 `hook_card`/`cta` 加 `enabled`；QC 按 profile 跳过字幕断言；违规词改为"仅音频口径 + WARN" |
| P1-2 | **语速 1.1–1.2x** | 时间轴全线换算（ASS/消音/xfade/V1 一致性） | 做成 `time_stretch` 开关，默认 1.0；1.2x 时所有时间戳统一乘 1/1.2 并在 QC 加"音画偏移"复测 |
| P1-3 | **多色处理** | 需颜色标注（CLIP/人体区直方图），准确率是瓶颈 | 先做"颜色清单 + 各色时长统计 + 偏好色占比 QC（WARN）"，颜色转场硬规则作为第二阶段 |
| P1-4 | **视频端构图**（头顶 ≤17%、等比、底边不动、对称裁切） | 每 clip 重构图会放大噪点/降低清晰度 | 复用 `normalize_subject_framing`，但只在"头像过大"时触发（头部占比 > 阈值），并加清晰度回归 |

### P2 — 探索/低优先
动态优先（运动能量）、情绪瞬间（音频 RMS 峰值）、搭配镜头数上限、素材目录名自动解析预填 spec、成片复制到素材目录、`afftdn` 轻降噪。

## 4. 不建议采纳（附理由）

| 文档要求 | 理由 |
| :--- | :--- |
| 删除助播话语 | 需说话人分离（pyannote 级），本素材以主播为主，投入产出比低；误删风险高于收益 |
| "不额外移动画面强行居中" | 该规则针对"放大后构图"的人工习惯；我们的封面/分镜是"全幅覆盖 + 钳制"，语义不同，强行对齐反而破坏现有通过率 |
| "稀缺=衣柜里少的那一件" | 是话术创作指导，属内容生成范畴；仓库侧只需保证不出现虚假稀缺（已有黑名单），无需新机制 |
| "卖点翻译成用户收益"、"提前解决痛点"、"颜色适合人群" | 均需生成式改写台词，与本仓库"只用真实素材原声、不生成口播"的硬原则冲突 |
| 输出"剪辑时间线/剪辑指令" | 已有 `plan.json`/`timeline.json`/`dialogue_script.json`，结构化程度更高，无需退回文本形式 |

## 5. 若采纳 P1-1（无字幕模式），需要同步动的断言清单

| 断言/环节 | 现状 | 无字幕模式下的处理 |
| :--- | :--- | :--- |
| 字幕零价格 / 字幕违规词零残留 / 字幕无繁体 / subtitle_banned_tokens / MarginV 安全区 | 均读 `subtitles.ass` | 全部跳过（记 SKIP 而非 PASS，避免"假绿"） |
| 成片 ASR V1 字幕-原声一致性 | 比对 ASS 与复检转录 | 跳过（无字幕可对） |
| 违规词策略 | 删字幕 | 退化为"仅记录"（声音保留本来就不处理音频） |
| 贴纸/Hook/CTA/品牌条 meta | 供人脸安全审核 | 相应元素不生成，meta 为空 |

> 这点必须写进 PR 说明：**无字幕模式下 QC 覆盖率会实质下降**，不能简单当"更宽松的同一套流程"。

## 6. 结论

1. **文档的最大价值不是"再加规则"，而是暴露了三处形态差异**：无文字成片、40s 下限、1.1–1.2x 语速。这三项决定的是"产品档位"，不是"参数微调"——需要你先决定要不要支持，再谈实现。
2. **仓库在"可量化、可回归"的维度上普遍更严**（违禁词、价格、句子完整性、响度、黑名单），文档在这些点上没有增量。
3. **真正的增量只有两块**：多色处理、主题款明确。前者是女装切片的刚需且高度可量化（偏好色占比、颜色转场一致），后者是无文字模式下的"注意力锚点"。
4. **低成本高收益的四项（P0）建议直接排进本迭代**，其中最推荐 P0-1（参数占比上限）和 P0-2（句级赘述去重）——改动小、可量化、立即提升成片观感。
5. 34 项自检里 44% 可自动化，13 项只能人工/采样 → 不必追求"全自动满足文档"，应把"人工判断项"沉淀到抽帧审核台（SOP §9 已登记的工具缺口）。
