## 二、特效元素：位置与时序

### 2.1 ① 顶部平台标识条（新增，常驻）

| 项 | 规格 |
|:--|:--|
| 位置 | `y=0`，贴画面最顶端（抖音生态的账号角标位） |
| 尺寸 | 宽 1080（满幅）× 高 **88px** |
| 底色 | `#101014`，不透明度 150（半透明，能看到底下的画面层次） |
| 内容 | 左侧金色圆形店铺图标（含店铺名首字）+ 店铺名（白）；右侧账号名（强调金 `#E2C98A`） |
| 文本来源 | `platform_bar.shop_name` → 缺省取 `brand.title_en`；`platform_bar.account` → 缺省 `@brand.subtitle_cn` |
| 时序 | **常驻**（0 ~ 成片结束），不受分镜切分影响 |
| QC | 「视频顶部平台标识」——除校验清单记录外，还对成片顶部条带做**像素级复测**（实测检出高亮像素 3929） |

> 设计意图：抖音生态中账号露出是合规与识别的基础。同时它天然承担了此前评估中
> "水印完全未实现"这一 P0 缺口的角色——但它更克制（一条窄带，不遮挡内容区）。

### 2.2 ② 挂角利益点徽标（新增，带时序）

**每分镜一枚**，出现在画面右上空白区，承载该分镜的核心卖点。

| 项 | 规格 |
|:--|:--|
| 位置 | 右上角 `x = 1080-220-40 = 820`，`y = 300`（避开顶部标识条与 Hook 卡） |
| 尺寸 | 220 × 220 圆角方块，金底 `#FFE9A8` + 描边 `#E8A91E` |
| 文案优先级 | ① spec `options.sticker_texts` 显式指定 → ② 分镜原文命中的具体卖点短语（3M新雪丽 / 半岛棉 / 显瘦 / 亲肤…）→ ③ 类目兜底（开场必看 / 面料细节 / 版型显瘦 / 一衣多穿） |
| 文案长度 | 截断到 8 字，方块内自动换行居中 |

**时序（关键）**——贴纸的出现与消失按**成片时间轴**计算，而非源素材时间：

```
分镜起点 t0 ──► 延迟 delay_ratio×分镜时长 ──► 淡入 fade_in ──► 稳定显示
                                                          │
                        淡出 fade_out ◄── 停留 hold_ratio×分镜时长 ◄──┘
```

| 参数 | 默认 | 含义 |
|:--|:--|:--|
| `delay_ratio` | 0.10 | 分镜内延迟 10% 启动，**避免与切点撞车**（贴纸不在画面刚切过去时闪现） |
| `fade_in_sec` | 0.35 | 淡入时长 |
| `hold_ratio` | 0.72 | 稳定显示时长占分镜长度的比例 |
| `fade_out_sec` | 0.35 | 淡出时长 |

> **实现要点**：静态 PNG 必须在 ffmpeg 输入侧用 `-loop 1 -framerate 30 -t <总时长>`
> 转成连续流，否则单帧 PNG 的时间戳恒为 0，`fade` 的 `st=9.85` 会让它永远保持透明
> （实测踩到：贴纸完全不出现）。改用连续流后时序精确：
> 0.5s→无 → 2.0s→可见 → 8.0s→消失 → 12/20s→第二张 → 30s→第三张 → 45/55s→第四张 → 62s→全消。

### 2.3 ③ 放大特效（推镜）：触发位置与过渡方式

**由"一次性静态裁切"升级为"分镜内定时缓动推镜"。**

| 项 | 规格 |
|:--|:--|
| 触发位置 | 分镜内 `zoom_effect.trigger_sec = 0.8s`（从分镜起点算）——**不是一进分镜就动**，先给观众 0.8s 稳定构图再推 |
| 过渡方式 | `zoom_effect.transition_sec = 1.2s`，**smoothstep 缓动**（`k²(3-2k)`，两端速度为 0，起止无突兀感） |
| 目标倍率 | `max_zoom = 1.35`（SKILL 规定 1.25~1.35） |
| 锚点 | `y_anchor = 0.35`（画面 35% 高度处），推镜时该点在屏幕上**保持不动**，主体不跑位 |
| 触发条件 | 分镜命中面料/工艺关键词（`FABRIC_KEYWORDS`）时 `zoom=1.3`，其余为 1.0（不推镜） |
| 实现 | ffmpeg `zoompan`（`d=1` 保证 1 输入帧 = 1 输出帧，`on` 为分镜内帧号） |

**缓动曲线实测**（静态标记图确定性验证，量测方块实际缩放比）：

| 时刻 | 缩放比 | 状态 |
|:--|:--:|:--|
| 0.3s | 1.020 | 触发前，静止 |
| 0.9s | 1.020 | 触发前，静止 |
| 1.1s | 1.060 | 开始上升 |
| 1.3s | 1.120 | 缓动中 |
| 1.6s | 1.240 | 缓动中 |
| 2.0s | 1.315 | 推满 1.3x |
| 2.5s / 4.0s | 1.315 | 保持 |

> `zoompan` 的 x/y 公式 `x=iw/2-iw/2/zoom`、`y=ih*0.35-ih*0.35/zoom`
> 保证 z=1 时是恒等变换（不推镜时无副作用），推镜时锚点固定。

### 2.4 ④ 镜像 / ⑤ 分屏（本次从死代码接入真实链路）

**根因**：此前 `clip["effect"]` 被硬编码为 `"none"`，而装配器里 hflip 与 split
的实现是完整可用的——**代码存在但永不触发**。本次把 `effect` 改为**决策变量**。

#### 镜像 hflip（SKILL 2.1）

| 项 | 规格 |
|:--|:--|
| 触发条件 | 非首镜的 `styling`/`fit` 分镜且未推镜；**每条成片最多 1 处**（避免观感割裂）；首镜是黄金 3 秒 Hook，不镜像 |
| 滤镜 | `hflip` 置于裁切之前（`crop` 会破坏镜像语义） |
| **防反文字遮挡**（SKILL 核心要求） | 镜像后背景招牌/LOGO 会反向。装配器对镜像分镜**多帧采样**（首/中/尾 3 帧）做 OCR 定位 → 只取画面**上半部分**（`y < 0.42H`，即背景店招区，不遮挡人物身上的印花）且面积 ≥ `min_box_area_px` 的文字框 → 外扩 10px 生成深色圆角遮挡贴纸 → overlay 回该分镜 |
| 无文字时 | 检测不到背景文字则**不做遮挡**（镜像本身无违和点），QC 记录为「未检出背景文字，镜像无违和点」 |
| QC | 「镜像防反文字遮挡」——BLOCK 级，镜像分镜未完成遮挡即拦截 |

#### 分屏 split（SKILL 2.3）

| 项 | 规格 |
|:--|:--|
| 触发条件 | **仅当 spec 显式提供 `options.split_pairs`**（含 `st` 与 `label_left`/`label_right`）时启用——不凭空捏造"另一款" |
| 合成 | 左右各 540×1920 半场 → `hstack` 拼接，音频取左半场 |
| 中缝分割线 | 8px 金色（`#E8A91E`）垂直线（SKILL 要求 6~10px） |
| 双侧标签 | 分割线两侧各一枚金色圆角胶囊标签（字号 30），距分割线 24px，y=120 |

### 2.5 ⑥ Hook 卡片 / ⑦ CTA 贴片（既有，本次微调）

| 元素 | 位置 | 时序 | 尺寸 |
|:--|:--|:--|:--|
| Hook 卡片 | 水平居中，y 动态避让人脸顶（实测 310） | 0 ~ 2.5s | **720×168**（原 640×130；2026-10-25 全局统一为 720 宽，尺寸由 `hook_card` 约束段驱动） |
