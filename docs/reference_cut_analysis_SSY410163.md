## 1. 素材片段的选取标准

### 1.1 片段时长区间

| 区间 | 数量 | 占比 | 示例 |
| :--- | :--- | :--- | :--- |
| < 2s | 1 | 10% | seg02 4.72~6.50（**1.78s**，全片最短） |
| 2 ~ 5s | 2 | 20% | seg03 6.50~9.34（2.84s） |
| **5 ~ 10s** | **6** | **60%** | seg06 29.04~38.84（9.80s）、seg07 38.84~47.73（8.89s） |
| ≥ 10s | 1 | 10% | seg04 9.34~22.31（**12.97s**，全片最长） |

**结论**：主体区间 **5~10s**，中位 6.29s；上限约 13s；下限不低于 1.8s（低于 1.8s 的
"碎切"在参考片里没有出现——seg02 的 1.78s 已经是极限）。

### 1.2 镜头类型与展示角度

对每段取 6 帧做 MediaPipe Pose 人体几何量化（`body_h` = 肩→踝归一化跨度）：

| 段 | 时间码 | 时长 | 景别 | body_h | 实际内容（联系表目视） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| seg01 | 0.00~4.72 | 4.72s | 中景 | 0.408 | **双裙并排**：一手拎卡其裙一手拎白裙，两色同框对比 |
| seg02 | 4.72~6.50 | 1.78s | 全身 | 0.549 | **低头看裙**：垂眼看手中裙身，弱化面部、突出裙 |
| seg03 | 6.50~9.34 | 2.84s | 全身 | 0.563 | **动态试穿**：转身走动，裙摆动态展示 |
| seg04 | 9.34~22.31 | 12.97s | 全身 | 0.520 | **站姿全身**：正面站立讲比例（全片最长） |
| seg05 | 22.31~29.04 | 6.73s | 全身 | 0.556 | **手势强调**：手在脸侧比划"显瘦/显高" |
| seg06 | 29.04~38.84 | 9.80s | 全身 | 0.674 | **做工细节**：镜头拉近讲蝴蝶结包边/手工搓制 |
| seg07 | 38.84~47.73 | 8.89s | 全身 | 0.532 | **配色出行**：拎包走动，奶白上衣 + 卡其裙 |
| seg08 | 47.73~53.59 | 5.86s | 全身 | 0.681 | **外套对比**：手持灰色大衣做搭配对比 |
| seg09 | 53.59~59.41 | 5.82s | 全身 | 0.588 | **举衣展示**：举起黑色衣物到胸前 |
| seg10 | 59.41~69.31 | 9.90s | 全身 | 0.678 | **白色收尾**：白色全套上身，完整成套 |

**量化结论**：
- **9/10 段为全身景别**，body_h 中位 **0.556**（区间 0.520~0.681）。
- **主体须完整入画**——只有 seg01（并排展示裙子）是 0.408，其余全部 ≥0.52。
  这与本仓库封面候选要求 `knees_visible`（保全完整人体）是同一取向。
- **展示角度不重复**：10 段覆盖了 10 种不同的"看商品的方式"
  （并排对比 / 垂眼看 / 走动 / 站立 / 手势 / 做工 / 出行 / 持物对比 / 举衣 / 成套），
  **相邻段无同质重复**。

> **判据口径修正（实施时发现）**：上表的 `body_h` = 肩→踝，受站姿/抬腿影响大——
> 换一套采样点后同一片段的 body_h 波动 **±0.08**，会把 3/10 段误判成非全身。
> 改用 **span = 头顶→踝**（人物在画面中的完整可见高度）后稳定得多：
> 参考片实测 span 区间 **0.473~0.996**、中位 **0.640**，全身段判据取 0.45 即 10/10 命中。
> 规则实现见 `src/tools/extract_shot_features.py`。

### 1.3 画面质量

参考片本身没有质量过滤痕迹（人工挑片），但可从其选择反推偏好：
- **无黑帧、无空镜、无纯 talking-head 空档**——最短的 1.78s 段（seg02）也是
  "低头看裙"，主体动作与商品强相关。
- 主体始终在画面内，且**商品（裙子）在每一段都可见或可讲**。

## 2. 素材与口播文案的过渡与对齐

### 2.1 切点与语音停顿的关系（本次分析最关键的结论）

对参考片音轨做 10ms 跳步 RMS 包络，逐切点取 ±0.6s 窗口内的局部谷底：

| 切点 | 谷底位置 | 偏移 | 该点电平 | 全片百分位 | 性质 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 4.72 | 4.67 | +0.05s | −21.4 dB | 54.8% | **句内视觉切点** |
| 6.50 | 6.50 | +0.00s | −90.2 dB | 0.2% | 语音接缝切点 |
| 9.34 | 9.40 | +0.06s | −29.8 dB | 20.8% | **句内视觉切点** |
| 22.31 | 22.31 | +0.00s | −85.9 dB | 0.2% | 语音接缝切点 |
| 29.04 | 29.02 | +0.02s | −120.0 dB | 0.0% | 语音接缝切点 |
| 38.84 | 38.81 | +0.03s | −109.0 dB | 0.2% | 语音接缝切点 |
| 47.73 | 47.74 | +0.01s | −76.3 dB | 0.3% | 语音接缝切点 |
| 53.59 | 53.61 | +0.02s | −72.7 dB | 0.4% | 语音接缝切点 |
| 59.41 | 59.41 | +0.00s | −120.0 dB | 0.0% | 语音接缝切点 |

**统计检验**：9 个切点中 **7 个（78%）位于 −60dB 以下的近数字静音区**；随机取 5000 个
位置作对照，低于 −60dB 的比例仅 **0.52%** → **富集 29 倍**。

**切点相对最近口播句边界的偏移**（ASR 句末）：
6.50(0.02s) / 9.34(0.18s) / 22.31(0.03s) / 29.04(**0.00s**) / 38.84(0.04s) /
47.73(0.27s) / 53.59(0.27s) / 59.41(0.37s) —— **中位偏移 0.03s**。

> ### ⚠️ 重要修正（后续验证推翻初版结论，务必读）
>
> 上面的"78% 切点落在数字静音"是**成片输出**的统计。后续用像素级验证过的映射
> （ref 53.59~58.95 ← src 120.55~127.37，部分帧 MAD=0.43）回到**源素材**检验，
> 结论反转：
>
> | 检验 | 结果 | 结论 |
> | :--- | :--- | :--- |
> | 源素材底噪 | min −53.4dB / p1 −46.0dB / 中位 −24.9dB | 源侧**不存在**数字静音 |
> | 绝对阈值 < −60dB 在原始素材上的命中 | **0 处**（六段素材全试） | 绝对阈值不可用 |
> | 源侧相对凹陷深度：切点处 vs 随机点 | 中位 **8.2dB** vs **9.4dB**，0/9 命中随机 95 分位 | **无富集** |
> | 逐帧溯源 | 参考片仅 1/10 段能与本目录素材 1:1 对上（其余来自更广素材池） | 参考片非本目录素材的直接拼接 |
>
> **即：参考片切点处的 −120dB 是「剪辑软件切音轨留下的拼接缝」，是拼接产物，
> 不是选段信号。** 真正可复现的规则是 **「切在 ASR 句末」**（偏移中位 0.03s / 最大 0.37s）。
>
> 这一修正直接改变了规则设计：
> - 规则主体 = ASR 句末边界（把本仓库 `_snap_end_to_sentence` 的容差从 2.0s 收紧到 0.45s）；
> - 语音气口只作**辅助精调**，且必须用**相对凹陷**判据（相对局部语流中位电平的下陷深度），
>   因为直播素材底噪高，绝对阈值命中 0 处。

### 2.2 两类切点的分工（重要区分）

| 类型 | 数量 | 判据 | 作用 |
| :--- | :--- | :--- | :--- |
| **语音接缝切点** | 7/9 | 落近数字静音（< −60dB），且紧贴 ASR 句末 | 换画面 + 换话题，**音画同时换气** |
| **句内视觉切点** | 2/9 | 落在有声区（4.72s / 9.34s） | **只换画面不换话题**，防止长句画面呆滞 |

例：切点 4.72s 落在「嗯这条裙子一定给大家做显瘦的…」（3.72~6.52）句中，
画面从"双裙并排"切到"低头看裙"——**语音连续，画面换角度**。
切点 9.34s 落在「这个裙子全都…」句中，同理。

### 2.3 重叠与留白

- **接缝切点处：零重叠、零额外留白**——前句结束（静音谷）与后句开始几乎同刻。
- **片段内部保留自然停顿**：句间 0.12~0.28s 的停顿**不切掉**，留在同一片段内
  （3.44~3.72 / 13.28~13.52 / 16.32~16.44 / 18.24~18.40 / 20.68~20.92）。
- **唯一的长停顿 1.32s（57.72~59.04）紧邻一个话题切换切点（59.41s）**——
  长停顿 + 换画面 = 段落感最强的位置。
- **语音占比 96.4%**：全片几乎没有空镜/冷场。删掉的口播极少（见 §3.3）。

## 3. 片段顺序编排逻辑

### 3.1 叙事骨架（实测顺序）

```
seg01~03  0.00~ 9.34  ( 9.3s)  痛点钩子 + 显瘦承诺
                          "怎么大家都好看 而且所有肚子胯有肉的姐妹不用担心"
seg04~05  9.34~29.04  (19.7s)  身材适配（比例/显高/小个子）
                          "如果你是1米55的话…感觉大家显得更高…腿太长了"
seg06     29.04~38.84  ( 9.8s)  做工细节（蝴蝶结包边 / 手工搓制）
                          "这个蝴蝶结是拿本部的这个包边…是用手搓的一个蝴蝶结"
seg07~10 38.84~69.31  (30.5s)  颜色与配色建议 + 收尾
                          "颜色是奶白色…裙子是卡其色…白配卡其色也OK"
```

### 3.2 卖点优先级

| 优先级 | 卖点 | 时长占比 | 理由（从话术与画面同现推得） |
| :--- | :--- | :--- | :--- |
| 1 | 痛点钩子（人群定位） | 13% | 开场 3.44s 直接点名"肚子胯有肉的姐妹" |
| 2 | 身材适配（显瘦/显高/比例） | 28% | 话题密度最高，连续 3 句讲比例与身高 |
| 3 | 做工细节（蝴蝶结） | 14% | 单点深挖 9.8s，6 句连续讲同一工艺 |
| 4 | 颜色/搭配 + 收尾 | 44% | 最长尾，含"纠结选哪个→建议→适合谁"完整决策链 |

**注意**：本片的顺序是 **hook → fit(比例) → fabric(做工) → styling(配色)**，
与本仓库当前漏斗顺序 **hook → fabric → fit → styling** **不同**。
差异原因：半身裙的卖点重心是**比例显瘦**而非面料质感——面料只占 14%。
→ **漏斗顺序应可按品类覆写，不能硬编码。**

### 3.3 内容取舍

- **无价格话术、无库存/上车/链接/发货叫卖**——`find_price_matches` 仅命中 "55"，
  且经核为「**1米55**」身高（**假阳性**）。
- **保留了极短的语义空句**：0.44s「为什么」、0.60s「我们家大衣」、
  0.88s「首先确实是」、0.68s「它还容易歪」。
  → **人工切片不做"短句即删"的激进裁剪**，只删与商品完全无关的内容。
- 保留了"纠结白色还是卡其色→我建议你买卡其色→为什么→因为…"这种
  **完整决策链**，说明**卖点之间要有推理过渡，不能只有结论**。
